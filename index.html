Google Sheets / Data Source Setup

For the first hosted version, the page can consume a published CSV from Google Sheets. Create a Google Sheet containing only management-safe fields, publish the relevant sheet/tab to the web as CSV, then paste its CSV URL below.

Recommended columns: company, sector, value, stage, probability, owner, month

For a multi-tab Google Sheets sync, we can later replace this with Google Apps Script. Do not put private contact details in a publicly published CSV.
